# 15.12 Air Systems - Revision Course

Recommended structure for the course website.

- `index.html` - course homepage (add this when ready)
- `chapters/15-12-turbine-engine-cooling/index.html` - Turbine Engine Cooling chapter
- Add future chapters as separate folders under `chapters/`

Example:

```text
air-systems-revision/
├── index.html
├── .nojekyll
├── chapters/
│   ├── 15-12-turbine-engine-cooling/
│   │   └── index.html
│   ├── next-chapter/
│   │   └── index.html
│   └── another-chapter/
│       └── index.html
└── README.md
```
