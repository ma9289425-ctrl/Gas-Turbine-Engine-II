# Gas Turbine Engine II - Interactive Revision

GitHub Pages-ready revision course.

## Structure

- `index.html` - course homepage
- `chapters/15-12-turbine-engine-cooling/index.html` - Turbine Engine Cooling
- `.nojekyll` - serves the static site directly

## Adding future chapters

Create a new folder under `chapters/`, place that chapter's file inside as `index.html`, then add its card/link to the course homepage.
